
# Health Insurance Analysis
---
This repository contains the code and documentation for analyzing health insurance costs based on various personal and geographical attributes. The project aims to identify factors that significantly influence insurance charges and provide insights for better cost management.

# Overview
Understanding the factors that affect health insurance costs is crucial for both providers and consumers. By exploring the relationships between personal attributes and insurance charges, we can better predict costs and implement strategies to minimize them. This project involves performing Exploratory Data Analysis (EDA) on a dataset containing various personal and geographical attributes to find key drivers of insurance costs.

# Dataset

The dataset includes:

- Personal attributes: age, gender, BMI, family size, smoking habits
- Geographical factors: region, location
- Insurance charges 

# Objective
- **Data Analysis:** Perform exploratory data analysis to understand the distribution of health insurance costs.
- **Correlation Analysis:** Identify factors that have a significant impact on insurance charges.
- **Insights and Recommendations:** Provide actionable insights based on the analysis to inform decision-making.
